## Paused

**[Rampart](https://github.com/aravmdn/rampart)** — AI coding agents run under enforced least
privilege: Windows Job Objects for process containment, Low-Integrity filesystem restriction,
per-app-ID WFP outbound filters. Blocks fire at the OS level, and each one comes back with an
explanation instead of a silent failure. Works and still installable; no active development since
May 2026. Apache-2.0.
