Third year CS at TU/e, in Eindhoven, and a software engineering intern at [Datagrove](https://datagrove.nl)
in Amsterdam. I build the infrastructure around AI agents: the parts that measure whether they
work, and contain them when they don't.

**[Parkbench](https://github.com/aravmdn/parkbench)** · `v1.2, paused, MIT`
A benchmark arena for AI agents, built as a theme park. Seven rides across four axes; the
negotiation and exchange rides score against a provable optimum instead of a rubric. 440 tests,
75 decision records, zero runtime dependencies, and every score reproducible byte-for-byte across
runs, processes and operating systems.

**[Suitewatch](https://github.com/aravmdn/suitewatch)** · `v0.1, MIT`
Fails the build when tests disappear, get skipped or start failing, even when the total stays the
same. Tests are matched by identity, so a swapped-out test can't hide behind an unchanged count.

**[Harshape](https://github.com/aravmdn/harshape)** · `v0.1, MIT`
Turns a browser HAR into a performance-only report you can share: timings and sizes stay, URLs and
payloads go. Offline, zero runtime dependencies.

**[Pitchr](https://pitchr.live)** · `live, MIT`
AI pitch coaching for founders. Live recording, transcription, async analysis runs, structured
scoring. Second-largest of four contributors.

**[Rampart](https://github.com/aravmdn/rampart)** · `paused, Apache-2.0`
AI coding agents run under enforced least privilege: Windows Job Objects, Low-Integrity
filesystem restriction, per-app-ID WFP outbound filters. Every block comes back with an
explanation instead of a silent failure. Works and still installable; no active development
since May 2026.

**[CollabBoards](https://github.com/aravmdn/CollabBoards)** · `shipped, MIT`
Real-time boards over Socket.IO with JWT access/refresh auth and a DB-backed integration suite.

**[CBL](https://github.com/aravmdn/CBL)** · `delivered`
A live installation where a singing bowl's pitch and a person's heartbeat drive the visuals,
GPU-side in TouchDesigner.

Smaller ones: [Folio](https://github.com/aravmdn/folio), an offline Markdown reader ·
